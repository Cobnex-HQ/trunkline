# Glacier Fold

The production Trunkline elephant identity uses the Glacier Fold direction. Vector sources are `trunkline-elephant.svg` and `trunkline-icon.svg`; `glacier-fold-master.png` is the raster reference. App-specific icon sets live in each app's Resources/Assets.xcassets.

`Scripts/MakeIcons.swift` generates platform assets. Inspect resulting icons at small sizes, in light/dark appearance and in the Dock before replacing production assets. Historical explorations and screenshots are not part of the public source tree.
