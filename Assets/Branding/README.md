# Glacier Fold

Trunkline uses the Glacier Fold elephant. Vector sources: `trunkline-elephant.svg` and `trunkline-icon.svg`. Raster reference: `glacier-fold-master.png`. Each app keeps its icon set in `Resources/Assets.xcassets`.

`Scripts/MakeIcons.swift` generates platform icons. Check small sizes, light/dark appearance and the Dock before replacing assets. Historical explorations and screenshots are excluded from the public source.
